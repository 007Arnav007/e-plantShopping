# e-plantShopping

## Project Overview
e-plantShopping is a React-based plant shopping application for Paradise Nursery. It allows users to explore plants and manage their selections in a shopping cart.

## Features
- Paradise Nursery landing page with a Get Started button.
- About Us section.
- Plant products organized into categories.
- Product images, names, descriptions, and prices.
- Add-to-cart functionality.
- Shopping cart quantity management and item removal.
- Automatic item subtotals and cart total.
- Checkout placeholder and Continue Shopping navigation.
- Responsive user interface.

## Technologies Used
- React
- JavaScript
- CSS
- Vite
- Redux Toolkit
- React Redux

## Installation and Setup
1. Clone the repository:
   `git clone https://github.com/007Arnav007/e-plantShopping.git`
2. Enter the project directory:
   `cd e-plantShopping`
3. Install dependencies:
   `npm install`
4. Start the development server:
   `npm run dev`
5. Build the production application:
   `npm run build`

## Project Structure
- `src/App.jsx` — main application and landing page.
- `src/AboutUs.jsx` — company information.
- `src/App.css` — landing page styling.
- `src/CartSlice.jsx` — Redux cart state and actions.
- `src/ProductList.jsx` — product listing and navigation.
- `src/CartItem.jsx` — shopping cart interface.
- `src/store.js` — Redux store configuration.
